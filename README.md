# 👾 Galaxy Invaders

Classic Space Invaders-style game built with vanilla HTML5 Canvas and JavaScript.

## 🎮 Play

**Live:** [http://ai-game-galaxy-855647970705.s3-website-us-west-2.amazonaws.com](https://d2mshmgnyh8rrg.cloudfront.net/)

## Features

- Classic arcade Space Invaders gameplay
- Multiple enemy types (👾 👽 🛸)
- Progressive difficulty with levels
- Particle explosion effects
- Starfield background
- Score tracking and lives system
- Keyboard and mobile touch controls
- Responsive design

## Controls

| Key | Action |
|-----|--------|
| ← → or A/D | Move ship |
| Space | Shoot |

On mobile: use the on-screen buttons.

## Tech Stack

- Pure HTML5 / CSS3 / JavaScript
- Canvas API for rendering
- No dependencies
- Hosted on AWS S3 (static website)

## Local Development

Just open `index.html` in a browser. No build step needed.
